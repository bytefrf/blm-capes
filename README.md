# BL-Modern Capes

Клиентский мод Forge 1.20.1 (Forge 47.4.10+, Java 17). Он получает публично назначенные плащи по контракту `POST https://bl-modern.ru/api/capes_public_v2.php` с JSON-телом `{"uuids":[...]}`. Серверный мод не требуется, а API-ключи и другие секреты клиентский мод не использует.

**Экспериментальная версия:** API сайта пока не опубликован; кастомные плащи и синхронизация двух игроков ещё не проверены в реальной игре.

Ответ принимается только в виде `{"success":true,"version":2,"capes":{"uuid":"code"}}`. Разрешены встроенные коды `blm`, `tfgm`, `axolotl`, `copper`, `bronze`, `steel`, `space`, `forest`, `flame`, `ice`, `dragon`, `ender`, `aurora`, `sunset`, `ocean`, `cherry`, `storm`, `royal`, `nebula`, `ember`, а также строго `custom_` + 64 строчных шестнадцатеричных символа SHA-256. Всё остальное игнорируется.

## Синхронизация и безопасность

- Раз в секунду мод собирает UUID игроков в загруженном мире и выполняет асинхронные POST-запросы батчами до 50 UUID. Запросы включены только при входе по адресам `play.bl-modern.ru` или `tfgm2.bl-modern.ru`; при подключении по IP, иному имени или в одиночной игре синхронизации нет.
- Рендер берёт только уже подготовленную текстуру: сетевых запросов, чтения файлов и декодирования изображений в render callback нет.
- Успешные ответы кэшируются на 60 секунд, сбои получают 30-секундную паузу; размер кэша ограничен 1024 игроками. Подключение и чтение имеют таймауты 5 и 10 секунд, а ответ ограничен 64 КиБ.
- Для `custom_<sha256>` текстура загружается только по фиксированному URL `https://bl-modern.ru/api/capes_texture.php?hash=<sha256>` без редиректов. До регистрации в GPU проверяются лимит 64 КиБ, PNG, точные размеры 64×32 и SHA-256 скачанных байтов.
- Одновременно хранится максимум 64 динамические custom-текстуры. Неиспользуемые текстуры освобождаются после отзыва назначения, истечения кэша, отключения и смены сессии; устаревшие результаты запросов не применяются.
- Мод не показывает свой плащ поверх уже загруженного штатного плаща, при невидимости, отключённой части модели плаща или надетых элитрах.

## Локальная отладка

После первого запуска файл `config/blmcapes-client.toml` содержит `testPlayerUuids`. UUID из этого списка принудительно получают встроенный плащ `blm` на данном клиенте и имеют приоритет над синхронизацией. Это только локальный отладочный override; он не отправляется в сеть.

## Сборка и проверка

Установите JDK 17 и выполните `gradlew.bat build`. Готовый jar находится в `build/libs`. Протокольные проверки запускаются через `gradlew.bat test`.
