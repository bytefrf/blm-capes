# BL-Modern Capes — тестовая версия

Клиентский мод Forge 1.20.1 (Forge 47.4.13+, Java 17). Показывает встроенный плащ с ванильным движением только у UUID, перечисленных в локальной конфигурации этого клиента. Он не меняет сервер и не передаёт данные в сеть. По умолчанию список пуст.

## Установка и тест

1. Поместите собранный `build/libs/blmcapes-0.1.0.jar` в `mods` клиентской сборки Forge 1.20.1.
2. Запустите игру один раз и закройте её. Откройте `config/blmcapes-client.toml`.
3. Укажите UUID игроков, например `testPlayerUuids = ["00000000-0000-0000-0000-000000000000"]`. Это пример, а не реальный UUID. Используйте UUID, который игроку назначил сервер BLAuth.
4. Запустите игру снова. Плащ появится только в клиенте с такой настройкой; чтобы его видел другой игрок, ему тоже нужны мод и те же настройки. В настройках скина Minecraft должен быть включён плащ.

Мод не перекрывает уже видимый штатный плащ; при невидимости и надетых элитрах он скрыт. Совместимость с другими визуальными модами и серверами нужно проверять в игре.

## Сборка

Установите JDK 17 и выполните `gradlew.bat build`. Готовый jar находится в `build/libs`.

## Ограничения

Это локальный прототип без сайта, магазина, проверки владения и синхронизации. Локальную настройку можно изменить, поэтому она не предназначена для платной выдачи. API без серверных ключей и выдача выбранного плаща появятся только при отдельной интеграции.
